# Chore Blitz

Family cleaning blitzes: an iPhone app to start, claim and finish chores, and an Apple TV board that shows who's doing what.

- `ChoreKit/` — the rules and models (Swift package, `swift test`)
- `Shared/` — CloudKit store used by both apps
- `iOS/`, `tvOS/` — the apps
- Generate the Xcode project with `xcodegen generate`.

See `docs/design.md` and `docs/plan.md`.
